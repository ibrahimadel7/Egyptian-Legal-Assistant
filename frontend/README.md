# المساعد القانوني المصري — Frontend

Arabic-first React 18 + Vite + TypeScript interface for an Egyptian legal information product. The chat UI is connected to the FastAPI RAG backend in `../egyptian-legal-rag`.

## Run locally

```bash
npm install
npm run dev
# In a second terminal, start the backend on http://127.0.0.1:8000
```

## Checks

```bash
npm run test
npm run build
```

## Legal content notice

All sample conversation/source text is illustrative UI test data only. It is not a verified statement of Egyptian law and is not generated by a legal retrieval system. The UI explicitly indicates when no legal source is connected.


## Run with the backend

1. Start FastAPI from the backend directory: `uvicorn app.main:app --reload --host 127.0.0.1 --port 8000`.
2. Start Vite from this directory: `npm run dev` (default `http://localhost:5173`).
3. Vite proxies `/api` and `/health` to FastAPI. Set `VITE_API_BASE_URL` only when the API is hosted separately.
4. Configure `GROQ_API_KEY` and build the vector index in the backend before sending chat questions.
